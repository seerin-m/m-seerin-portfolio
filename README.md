# M Seerin — Professional Spa & Wellness AI/ML Portfolio

A calm, tranquil, spa-inspired Single Page Application (SPA) portfolio for **M Seerin (AI/ML Engineer)**, built with Vite, React, Tailwind CSS, and LocalStorage.

## 🌿 Design & Aesthetics
- **Theme**: Deep Sage Green (`#0f1814`) + Soft Warm Sand (`#f7f2e8`) & Muted Gold accents.
- **Typography**: Playfair Display (Serif headings) + Plus Jakarta Sans (Readable body font).
- **Aesthetic**: Glassmorphism, smooth scroll, soft ambient blur, subtle hover micro-interactions.

---

## 📑 9 Sections in Order
1. 🏠 **Home**: Hero section, tagline, short intro, and primary CTA buttons.
2. 👨 **About Me**: Professional summary, background story, and academic record at Anand Institute of Higher Technology (9.2 CGPA).
3. 🛠 **Skills**: Categorized skill matrix (AI & GenAI, Languages & Frameworks, Edge Infra) with percentage mastery bars.
4. 💼 **Experience**: Detailed timeline for **F22 Labs** (Kokoro-82M adaptation, LiveKit, Qdrant, vLLM) & **UPTOSKILLS**.
5. 📂 **Projects**: Card grid showcasing *Educalria*, *Local Mobile TTS Inference (Inflect-Nano-v1)*, and *Nova OS Voice Assistant* with tech tags & GitHub links.
6. 🏆 **Certifications**: Verified NPTEL Python, HDCA, and AI/ML Workshop credentials with link triggers.
7. 📝 **Blogs**: Dynamic technical blog cards with **LocalStorage creation/drafting** and expand/collapse post reader.
8. 📄 **Resume**: Embedded resume document view + direct **Download Resume** button.
9. 📞 **Contact**: Direct email/phone/social channels + contact form with **LocalStorage message history**.

---

## 🛠 Tech Stack & Tools
- **Frontend**: React 18, Vite 6
- **Styling**: Tailwind CSS 3.4
- **Icons**: Lucide React
- **Storage**: Browser LocalStorage (`useLocalStorage` custom hook)

---

## 🚀 Setup & Execution Instructions

```powershell
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```
