# M Seerin — Professional Portfolio

## 🛠 Tech Stack & Tools
- **Frontend**: React 18, Vite 6
- **Styling**: Tailwind CSS 3.4
- **Icons**: Lucide React
- **Storage**: Browser LocalStorage (`useLocalStorage` custom hook)

---

## 🚀 Setup & Execution Instructions

```powershell
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```
